# Plan

## Start

Identify the target project and read its instructions, relevant context, and [shared conventions](../../references/stack-contract.md). Reuse its existing notes, docs, or wiki and their format. If none exists, ask whether to use [jstack wiki](../wiki/SKILL.md); keep the discussion in the conversation if declined. Change the project's agent instructions only when asked.

## Discuss

Clarify the outcome, scope, constraints, and tradeoffs. Inspect code and references for factual answers; reuse settled context. Ask questions normally and use [grill-me](../grill-me/SKILL.md) when the user requests a structured interview. Accept its settled conclusions without repeating the interview. Keep requirements, proposals, observations, and accepted decisions distinct; acceptance or delegated judgment establishes a decision, not silence.

## Save

After decisions or meaningful changes, update the notes with current decisions, their reasons, and open questions that affect the plan or next step. When a decision changes, record why. Preserve existing history without requiring a separate discussion log. Follow the existing documentation system; when using jstack wiki, use its skill to maintain links and build/check the reader.

## Continue

Briefly state what is settled, what remains open, and the next useful step. Respect the user's phase and existing authorization; planning alone does not authorize implementation or mark behavior implemented or verified. Do not ask again for decisions or actions already authorized.
