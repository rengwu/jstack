# Visual spikes

Create 3–4 distinct visual prototypes for the user's brief. Use [grill-form](../grill-form/SKILL.md) to ask which direction they want to refine. Show each prototype as a separate option in one single-choice question, with its own preview and a neutral label.

Once the user picks a direction, refine that prototype using their feedback.
